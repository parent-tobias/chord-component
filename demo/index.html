Individual Chord Diagrams

Display individual chord diagrams for different instruments. When the instrument is guitar or ukulele, type any chord name and cycle through all the available voicings.

— 
<chord-diagram chord="C" instrument="ukulele" voicing-index="0"></chord-diagram>

Chord Lists

Display multiple chords in a responsive grid layout:

<chord-list instrument="ukulele" chords='["C", "F", "G", "Am"]'></chord-list>

How chord resolution works

v3.0 uses a tiered chord-lookup pipeline. For each <chord-diagram>, we try, in order:

  1. Host-provided chordFingers prop — an explicit override set via JavaScript.
  2. User-saved override — a fingering the user saved through <chord-editor>, stored in IndexedDB.
  3. @svguitar/chords-plugin — for standard guitar and standard GCEA ukulele only. Ships ~9k guitar chords and ~7k ukulele chords with multiple voicings each.
  4. Hand-curated system defaults — for anything the plugin doesn't cover (baritone ukulele, 5ths ukulele, drop-D guitar, mandolin, custom instruments).
  5. Dynamic generation — compute a fingering on the fly from the chord's notes and the instrument's tuning. Last resort.

The green badge above means the current instrument hits tier 3 (plugin). The orange badge means we're using tiers 4 or 5.

API Documentation

chord-diagram

Displays a single chord diagram.

  • chord (string): The chord name (e.g., "C", "Am7", "F#dim")
  • instrument (string): Instrument ID (default: "ukulele")
  • voicing-index (number, v3.0+): Which plugin voicing to use (default: 0). Only applies to plugin-covered instruments.
  • hide-label (boolean): Hide the chord name below the diagram

chord-list

Displays multiple chord diagrams in a responsive grid.

  • instrument (string): Instrument ID (default: "ukulele")
  • chords (string|array): JSON string or array of chord names

Helper exports (v3.0+)

  • searchChords(prefix, instrument?, limit?) — autocomplete chord names.
  • chordNames(instrument?) — list every chord the plugin can play on the instrument.
  • chordVoicings(chord, instrument?) — how many voicings the plugin has for a chord.

All three are async and return safe empty results when the optional @svguitar/chords-plugin peer dep isn't installed.

Built-in Instrument IDs

  • ukulele — Standard Ukulele (plugin-covered)
  • guitar — Standard Guitar (plugin-covered)
  • baritone-ukulele — Baritone Ukulele
  • ukulele-5ths — 5ths tuned Ukulele
  • guitar-drop-d — Drop-D Guitar
  • mandolin — Standard Mandolin
